Projects people have built on the VRChat API. **Built with** names the SDK a project depends on, where it uses one.

<Callout type="info">
These projects are independent. Neither VRChat nor this project has reviewed or endorsed them, so treat any app that asks for your VRChat login with the same care as any other.
</Callout>

## Desktop apps

| Project | What it does | Built with |
| --- | --- | --- |
| [VRCX](https://github.com/vrcx-team/VRCX) | Friendship management tool for VRChat | |

| [VRCNext](https://github.com/shinyflvre/VRCNext) | Windows launcher for managing friends, groups and more | |
| [vrc.zip](https://github.com/TheArmagan/vrc.zip) | Runs on your own machine with several accounts, live presence, a searchable feed, node-graph automations and a local API | |
| [XYVR](https://github.com/hai-vr/XYVR) | Merges VRChat, Resonite and ChilloutVR contacts into one address book | |
| [VRC Worlds Manager](https://github.com/Raifa21/VRC-Worlds-Manager-v2) | Organizes and stores your favorite worlds | |

| [VRCEmoji](https://github.com/Wakamu/VRCEmoji) | Converts GIFs into spritesheets for animated emoji | [.NET](/dotnet) |

| [VRC Avatar Manager](https://github.com/Narazaka/vrc_avatar_manager) | Switches between many avatars from a VR overlay such as XSOverlay | [Dart](/dart) |
